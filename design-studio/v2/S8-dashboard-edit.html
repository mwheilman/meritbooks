Live, in place

Customize doesn’t open a separate editor. Figures stay real and keep refreshing, so you arrange the home you’ll actually use.

Only what you may see

The catalog is filtered by permission before it renders. There’s no “locked” card teasing a widget you can’t use; the footer says the rest exists.

Required means locked

A required widget can move and resize under Add & move, but its remove control becomes a lock with the reason. Removing it from the layout JSON reinserts it.

Snap, don’t stretch

Resize offers only the sizes the widget declares. The corner handle and the size chips do the same thing; the chips are the keyboard path.
