MeritBooks Design System v2

One system, two densities. Annual Report sets the owner’s screens: editorial Syne titles, statement rules, notes to the figures. Operator Cockpit sets the work screens: the Midnight frame, 48px rows, keys printed beside the verbs, the slash meter.

Two marks run through it. The slash measures: the monogram’s 45° stroke counts confidence, close steps and clients ready. The note explains: anything the AI touched carries a note reference, and the note shows its evidence as a ledger that sums. Every home opens on work, with a 32px context line and no banner.

No banner heroes

Above the fold: the bar, a 32px context line, then the primary module in the top-left 8 of 12 columns.

Every number has a comparison and a destination

If a figure has no “vs” and nowhere to go, cut it.

Every module has one primary action

An empty state and a done state too. A widget the user can’t use isn’t rendered.

Use the IA’s words

Client, company, workspace, consolidation group, own books. See IA-SPEC §1.1 for the banned list.
