Fill, don’t find

Most vendors can’t find last year’s W-9. Filling it here makes a signed IRS form, and the TIN is typed, never photographed, so it never goes to a model.

The read is shown back

Each value sits beside the crop it came from. A vendor can fix what they typed, not what their insurer printed: for a certificate the only fix is a new one.

Short is specific

“Umbrella 1,000,000, needs 2,000,000” is a sentence an agent can act on. “Non-compliant” is not. The agent gets the same sentence.
