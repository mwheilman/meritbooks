Decisions first, figures beside them

No banner and no greeting. The left 8 columns are the work: one payment run, one bill, one question, one sign-off. The right 4 are what you’d check before approving: cash, margin, what’s due.

The slip proves the button

The payment run lists its vendors in a ledger that sums, closed by the statement’s blue double rule. The Approve button carries the same 186,420.55. Approving is signing the total.

Intercompany never inflates a figure

At a glance and the client table exclude intercompany fees by the related-client flag, so they don’t need a consolidation grant to be honest. The group view is the only place eliminations are computed.

Every number goes somewhere

Each glance figure is one link with two comparisons. Each client row opens that client. Each statement line opens its report. The layers icon marks group members.

S6//Privacy

Figures hidden for screen-sharing

Hide figures turns every amount, ratio and comparison into a bar of the same width. Nothing reflows, so the layout still reads, and names, counts and dates stay visible so Mike can still talk through it.
