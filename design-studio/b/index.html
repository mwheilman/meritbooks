Operator Cockpit

2026//MeritBooks//Direction B

Rationale

Merit is professional services built by operators, so MeritBooks should feel like an instrument, not a dashboard. The brand guide gives us the system: Midnight is the frame — rail, command bar, the full-bleed band that states the portfolio’s position, the bottom line of the income statement. Everything you read and act on sits on Warm White, where Midnight body text and DM Sans tabular figures stay crisp. Electric Blue is the only signal: the title, the focused row, the primary action, the focus ring. Syne appears a handful of times per screen, where a number or a headline deserves it.

Speed is the product. Every action has a key, every key is printed where the action lives, and the review queue works like a triage inbox: AI proposes, a person approves with one keystroke, the engine posts the balanced entry it already showed you.

What we took from the best
Linear
Elevation from lightness steps, not shadows. One chromatic accent. 32–48px rows.
Superhuman
The queue is a to-do list. One question per item. J/K and single-letter verbs.
Raycast
Shortcuts printed next to the action, never hidden in a tooltip. ⌘K finds the rest.
Vercel
:focus-visible rings, tabular figures, status never by color alone, one decimal convention per context.
Ramp
Group repeat spend so a person approves a batch, not 4 rows.

Signature: the Slash Meter

The guide separates every label with “//”. The monogram is built from 45° strokes. We drew a single glyph from both: a parallelogram tick at the M’s exact 45°, spaced like the separator. Lined up, the ticks measure things.

It’s one system everywhere: five slashes for AI confidence, six for the close steps on each entity, one per book for the consolidated lock count. You read it by count, not by color — the number always sits beside it, an open slash marks the current step, a red slash marks the one that’s stuck. Nobody else can own it, because it’s cut from Merit’s mark.

8-pt spacing (4 for optical nudges). 12-column grid, 24 gutters, 32 page margin. Rows: 32 statement · 48 queue and entity board. Square corners everywhere except keycaps (2px, so they read as keys). Status colors are tuned dark to sit beside Midnight and Steel: brick #B42318, spruce #1F6E50, ochre #8A5A00 — all AA on white.
