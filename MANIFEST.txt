INTERIM BRIDGE AUTH (§3A.9 b/c) — only matters until merge:
  - Per-module shared service token. Set env AI_GATEWAY_SERVICE_TOKENS="PROJECTS:<secret>,BOOKS:<secret>"
    (format MODULE:token, comma-separated). No env set => the HTTP bridge is DISABLED (fail closed).
    The caller sends header  x-merit-service-token: <secret>  matching its module.
  - Caller asserts tenant_id + user_id in the body. If user_id is set, the bridge verifies an ACTIVE
    core.memberships row for that user in that tenant and DENIES if absent (fail closed). core.users /
    core.memberships are NOT built yet (Identity/Access §4 is future Core work), so user-attributed HTTP
    calls will deny until Core ships them — by design. user_id = null = tenant-scoped service principal,
    authorized by the token alone (used for agent/system calls and for verification today).
  - Do NOT build Clerk M2M / signed requests / mTLS for this path; it is being retired.
